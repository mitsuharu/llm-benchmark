# 測定結果

ベンチマークの結果一式には、問題文、各回の回答本文、採点と根拠、計測値、実行環境を含める。問題文は計測時のベンチマーク版と問題 ID で参照する。未計測・未評価の値は `null` とし、速度と品質は別評価にする。機密を含む生ログは `local-runs/` に保存する。

- `results/v0.1.0/<run-id>/result.json` に、モデル、ランタイムと設定、実行環境（OS、CPU、GPU、VRAM、RAM）、問題別の集約結果を保存する。使用 GPU と検出 GPU は区別する。各問の `repetitions` に回番号、計測値、得点と採点根拠を記録する。
- 同じ run ディレクトリの `answers.json` に、各回の最終回答本文を保存する。必要に応じて公開承認済みの成果物も同じディレクトリに添付できる。

Pages の計測詳細に回答本文を表示するには、公開承認を得た本文を同じディレクトリの `answers.json` に保存する。形式は問題 ID ごとに回番号をキーとするオブジェクト（例 `{"ja-01":{"1":"回答本文"}}`）。本文はテキストとして表示する。計測結果の `repetitions` に対応する回番号を指定し、公開しない回は省略する。

## 投稿と削除

投稿用 Skill を使用し、独立採点を `independent`、自己採点を `self` と明記する。`benchmark_commit` に受験時の SHA を記録する。公開前に `result.json` と回答本文を含む `answers.json` の候補を利用者に提示する。承認済みの範囲を投稿し、マージ後に Pages の計測詳細で対応する問題と各回のデータを確認する。

削除は該当 run ディレクトリを削除する PR を作成し、管理者がマージする。公開ページからは次回ビルドで消えるが Git 履歴や fork には残る。
