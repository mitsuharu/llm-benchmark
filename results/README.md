# 測定結果

`results/v0.1.0/<run-id>/result.json` に公開可能な結果を保存する。回答や成果物も同じrunディレクトリに保存できる。未計測の値は null。速度と品質は別評価。自己評価は区別する。機密を含む生ログは local-runs/ に保存する。

Pages の計測詳細に回答本文を表示するには、公開承認を得た本文を同じディレクトリの `answers.json` に保存する。形式は問題 ID ごとに回番号をキーとするオブジェクト（例 `{"ja-01":{"1":"回答本文"}}`）。本文はテキストとして表示する。計測結果の `repetitions` に対応する回番号を指定し、公開しない回は省略する。

## 投稿と削除

投稿用Skillを使用し、独立採点を independent、自己採点を self と明記する。1 run につき各問題の集約結果を1件保存する。反復の生データは別ファイルに保存可能。benchmark_commit に受験時のSHAを記録する。削除は該当runディレクトリを削除するPRを作成し、管理者がマージする。公開ページからは次回ビルドで消えるがGit履歴やforkには残る。
