# バージョン管理

VERSION は開発中の現行版。リリース時に vX.Y.Z タグで固定する。公開済みの benchmarks/vX.Y.Z と rubrics/vX.Y.Z.md は変更せず、新版へ複製して更新する。誤字修正はpatch、問題追加はminor、既存問題の意味や採点変更はmajorを原則とする。0.xでも公開済み版は固定する。
結果は版ごとに集計し、異なる版の合計点を混ぜない。問題IDは意味が変わる場合に新規IDを割り当てる。結果には benchmark_version と benchmark_commit（受験時のコミットSHA）を記録する。
タグ作成は管理者がレビュー済みコミットに対して行う。自動タグ作成は未実装。
