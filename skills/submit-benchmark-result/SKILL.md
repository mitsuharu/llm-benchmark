# 結果投稿

受験者とは別の担当エージェントとして実行する。計測値や採点結果を捏造しない。
[結果の形式](../../results/README.md) と対象版の manifest.json を確認し、`result.json` に実行環境・集約結果・各回の計測値と採点根拠、同じ run の `answers.json` に公開候補の最終回答本文をまとめる。問題 ID と回番号が両ファイルで対応することを確認する。未計測は `null`。自己採点は `evaluation_type` に `self` と記録する。
回答本文を含む公開候補から秘密、個人情報、内部推論ログを除去する。利用者には両ファイルを提示し、承認された範囲を公開する。承認されていない回答は `answers.json` の対象から外す。
ローカルで `scripts/validate.py` と `scripts/build_site.py` を実行する。利用者の承認後、専用ブランチに `results/` の対象 run だけを追加して PR を作成する。マージは利用者の別途依頼に従う。
マージ後は Pages のデプロイを確認し、計測の詳細ページで実行環境、問題文、各回の計測値・採点根拠、承認済みの回答本文が表示されることを確認する。詳細ページの URL を利用者に渡す。
削除は対象runを指定し、別PRでディレクトリ全体を削除する。Git履歴や複製からの完全削除ではないことを説明する。
