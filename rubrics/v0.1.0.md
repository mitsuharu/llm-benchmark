# 評価者専用：LLM実務能力ベンチマーク v2

受験者には渡さない。受験者へはSKILL.mdのみ、または同じ実行ルールと対象問題のみを渡す。公開問題につき既知の問題への過学習は排除できない。

各項目を1（満たす）、0.5（部分的）、0（満たさない）で評価し根拠を添える。問題点数は配点×項目平均。各問3回を独立した会話で実施し平均、全問合計100点。未実施は欠測とし100点換算しない。モデル名を隠して同一評価者・基準で採点する。JSON指定は実際に構文・キー・値・型を確認する。コードの目視評価と実際のビルド・テストを区別する。

モデル、量子化、ランタイム、コンテキスト長、thinking設定、temperature、出力上限、スキル版、反復番号を別途記録する。入力・生成速度やTTFTはランタイムの実測値を記録し、未提供なら欠測とする。速度は品質点に混ぜない。スキル全文入力と問題単独入力は別条件として比較する。
